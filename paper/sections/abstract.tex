\begin{abstract}
  Transformers trained on an ordered bigram copying task can represent multiple features using shared embedding directions, with meaning carried partly by differences in attention-weight magnitudes.
  This challenges interpretation methods that treat transformer features, and sparse autoencoder (SAE) latents trained on them, primarily as independent feature presence indicators.
  In this toy setting, high-performing SAEs frequently learn graded latents, where different activation magnitudes correspond to different bigram orderings.
  Steering these latents changes the order of model outputs, suggesting that their magnitudes have some causal influence.
  In our primary SAE, one graded latent strongly correlates with the difference between the separator token's attention to the first and second input symbols at $r=0.807$ (compared to $|r| < 0.004$ for 98\% of latents), and multiplicative steering swaps 49.8\% of all outputs, or 77.8\% conditional on latent activation.
  Anonymised code is available at \url{https://anonymous.4open.science/r/graded-latents-70FA}.
\end{abstract}
