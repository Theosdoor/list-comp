\section{Methodology}\label{s:method}

We study a two-layer attention-only transformer trained on the ordered bigram copying task introduced by \citet{farrell2025order} (Table \ref{tab:model_config}). The model encodes bigram $(d_1,d_2)$ into a single separator token, $s$, and reconstructs it as $(o_1,o_2)=(d_1,d_2)$. The five input positions are represented as $[d_1, d_2, s, o_1, o_2]$, where tokens at $d_1$ and $d_2$ are symbols uniformly sampled from $[0,99]$ and $s, o_1, o_2$ contain special tokens. This gives 10,000 possible ordered bigrams.
\citet{farrell2025order} find that the residual at $s$ after the first layer is:
\begin{equation*}
    \boldsymbol r^{L_1}_s = \alpha_{s\to d_1} (\boldsymbol E_{d_1} + \boldsymbol P_{d_1}) + \alpha_{s \to d_2}(\boldsymbol E_{d_2} + \boldsymbol P_{d_2}) + \boldsymbol E_s + \boldsymbol P_s
\end{equation*}
where $\alpha_{s\to d_i}$ is the attention weight in the first layer for query $s$ and key $d_i$, and $\boldsymbol E_{x}$ and $\boldsymbol P_{x}$ are the token and positional embeddings for the token at $x$ respectively.
Thus, the model represents bigram orderings at $s$ using a linear combination of shared embedding directions, $(\boldsymbol E_{d_1} + \boldsymbol P_{d_1})$ and $(\boldsymbol E_{d_2} + \boldsymbol P_{d_2})$, with coefficients defined by the attention probabilities.
% the relative magnitude of scalar attention weights, rather than representing each possible ordering as a different direction in activation space (which other composition methods do \citep{wattenberg2024relational}).


Models can represent more than $n$ features in $n$-dimensional activations through superposition, which complicates interpretability \citep{elhage2022toy}. SAEs decompose dense, superposed model activations into sparse feature representations \cite{bricken2023monosemanticity}.
We train BatchTopK \cite{bussmann2024batchtopk}, JumpReLU \cite{rajamanoharan2024jumping} and Matryoshka \cite{bussmann2025learning} SAEs on $\boldsymbol r_{s}^{L_1}$ using implementations from \citet{marks2024dictionary_learning}. 
SAEs are trained on residual activations on the full finite input space of the toy task (10,000 inputs). 
Since our goal is not out-of-distribution generalisation, we do not need a train/test split.
% Our goal is instead to determine whether SAEs recover the known internal computation implemented by the transformer.
We evaluate SAEs on sparsity ($L_0$) and loss recovered \cite{karvonen2025saebench,ferrando2024primer} over the complete activation distribution.

After a grid search (Table \ref{tab:btk_sae_sweep}) we find that BatchTopK SAEs with $k \in [3,5]$ all achieve similar top performance, so we select $k=3$. We select $d_\text{SAE} = 128$ which achieves similar performance to larger $d_\text{SAE}$. We filter for loss recovered over 0.999 and use the checkpoint with the fewest dead latents ($3.1\%$). Table \ref{tab:sae_config} shows the final configuration.

We inspect latent activations using activating examples, firing rates and correlations with the difference between the separator token's attention to the first and second input symbols,
\( 
\Delta \alpha = \alpha_{s \to d_1} - 
\alpha_{s \to d_2}
\). \citet{farrell2025order} find that $\Delta \alpha$ distinguishes bigram orderings at $\boldsymbol r_{s}^{L_1}$. We hypothesise that latents related to order correlate with $\Delta \alpha$ more strongly than other latents.
To test whether a latent is graded, we perform causal steering interventions inspired by \citet{brien2025steering}.
For a given latent, we replace its activation magnitude $m$ with $m' = pm$ for some scale factor $p$. We reconstruct and replace the original activation at $\boldsymbol r_{s}^{L_1}$ and observe changes in the output logits. We repeat across all $p \in [0, 10]$ (step $0.05$) and all input bigrams. If the latent is graded, varying $p$ should systematically change the model's output ordering.
% We hypothesise that special latents have graded activations. Specifically, we hypothesise that they have activation ranges corresponding to different bigram orderings. To test this hypothesis, we perform steering by linearly scaling special latent activations and observe whether the model's outputs change predictably.

We test for latents correlated with $\Delta \alpha$ across a sweep of 2,613 SAEs spanning multiple architectures and hyperparameters (Table \ref{tab:sae_sweep_configs}).
For computational feasibility, we only perform steering on the primary BatchTopK SAE and six additional selected high-performing checkpoints (Table \ref{tab:selected-saes}), chosen to span architecture, dictionary size and sparsity settings. We therefore treat the steering results as exploratory rather than statistically significant.
